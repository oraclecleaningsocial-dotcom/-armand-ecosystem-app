# -armand-ecosystem-app
App mobile-first in italiano per la gestione personale completa di Armand: pasti, ricette, lista della spesa, finanza personale, allenamenti, salute, farmaci, note, meteo, notifiche e suggerimenti intelligenti. Prototipo React con stato locale, localStorage e dashboard intelligente.

## warehouse-app/
App mobile Flutter, separata e offline-first, per la gestione della logistica di magazzino di una piccola attività (scansione barcode/QR, entrate/uscite, anagrafica prodotti, storico movimenti, alert scorte basse). Vedi [`warehouse-app/README.md`](warehouse-app/README.md) per architettura e istruzioni.
